# KH Real Estate – موقع تجريبي

موقع ثابت (HTML/CSS/JS) بدون سيرفر، منشور على GitHub Pages.

## الصفحات
- `index.html` الرئيسية
- `listings.html` البحث والفلترة مع الخريطة
- `property-<id>.html` صفحة لكل عقار (بتنولّد تلقائياً)
- `property.html?id=<id>` نفس صفحة العقار (احتياط)

## إضافة أو تعديل عقار
1. عدّل `assets/data.js` (وحط الصور بـ `assets/img/` بصيغة jpg).
2. شغّل: `python3 tools/build.py`
   - بيولّد صفحة لكل عقار مع معاينة الرابط (الصورة والعنوان والسعر) على واتساب وفيسبوك وتلغرام.
   - بيرسم صورة المشاركة بـ `assets/og/`.
3. ارفع التعديلات على `main`.

لما ينتقل الموقع لدومين جديد، غيّر الرابط بـ `tools/site.json` وشغّل البناء من جديد.

الموقع مخفي عن محركات البحث خلال فترة التجربة (`noindex` و `robots.txt`)، بس معاينة الروابط على السوشال مسموحة.
